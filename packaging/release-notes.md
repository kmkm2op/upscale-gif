## Download

| System | File |
|---|---|
| Windows 10/11 (64-bit) | `upscale-gif-*-windows-x64.zip`: extract it and run `Install.cmd` |
| Linux (x86-64) | `upscale-gif-*-linux-x86_64.tar.gz`: extract it and run `./install.sh` |

Everything is included: Upscayl's upscaler, its 18 AI models and ffmpeg. Four models
(UltraSharp, Remacri, UltraMix Balanced, UniScale Restore) are for non-commercial use only. You need a GPU with a
Vulkan driver; on Linux also glibc 2.35+ (Ubuntu 22.04, Debian 12, Fedora 36 or newer)
and zenity for the windows.

`upscale-gif-*-sources.tar.gz` holds the source code of the bundled GPL/AGPL programs.
